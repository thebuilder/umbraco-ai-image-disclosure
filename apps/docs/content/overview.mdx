AI Image Disclosure classifies Umbraco Image media from signed C2PA Content Credentials. The result gives editors and frontends a small, predictable contract without exposing the complete manifest.

## What is C2PA?

The Coalition for Content Provenance and Authenticity, or C2PA, publishes an open standard for cryptographically verifiable media provenance. A C2PA **Content Credential** can record where an asset came from, how it was changed, which tools were involved, and whether AI played a role.

AI Image Disclosure verifies the signed credential before using its claims. It does not treat the presence of metadata as proof on its own. Read the [official C2PA explainer](https://c2pa.org/specifications/specifications/2.2/explainer/Explainer.html) or see [C2PA and the EU AI Act](/c2pa-eu-ai-act) for the complete distinction.

## Stored properties

| Alias | Value | Purpose |
| --- | --- | --- |
| `aiDisclosure` | `generated`, `modified`, or empty | The public classification |
| `aiGenerator` | Text or empty | The software agent named by C2PA |
| `aiDisclosureSource` | `C2PA`, `Manual`, or empty | How the current value was set |

The empty value means **not determined**. It does not mean the image is human-made.

## Backoffice experience

Classified images receive the matching European Commission disclosure badge in the supported Media collection view. Editors can change the disclosure when metadata is absent or the classification needs correction. The [official EU icon guidance](https://digital-strategy.ec.europa.eu/en/policies/eu-icons-labelling-ai-generated-content) explains the available label variants and their intended use.

The package does not replace Umbraco's native media picker or thumbnail components. It only adds a badge through a supported collection extension point.

## What detection can establish

Detection answers a narrow question: does a valid C2PA provenance chain contain positive evidence that this image was generated or modified using AI?

It does not infer provenance from pixels, filenames, or unsigned metadata. See [Classification](/classification) for the exact rules and [Operations](/operations) for limits and platform support.
